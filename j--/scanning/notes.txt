[Problem 1 (Multiline Comment)]

Goal: Add support for multiline comments into j-- in the format /*<comment body>*/

Approach: Within Scanner.java, I modified the code concerning scanning of the / character.
When a * is found directly after a /, then we have entered a multiline comment. I set a boolean
called inComment to true to track if we are inside a multiline comment. I also set an integer to
the current line number for error reporting. We then enter a while loop where we ignore all
characters until we see a * followed by a / to exit comment. We then set inComment to false and break
to exit the loop. This allows the scanner to pass over all characters within the multiline comment.
Once outside the loop, we check to see if inComment is true. If it's true, then report an error as 
we never exited the multiline comment before the EOF character. Here is where the start line number is reported.

[Problem 2 (Reserved Words)]

these reserved words: break, case, continue, default, double, long, switch.
